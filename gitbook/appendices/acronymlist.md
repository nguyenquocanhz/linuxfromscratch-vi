# A. Từ viết tắt và thuật ngữ

* **ABI** — Application Binary Interface (giao diện nhị phân ứng dụng)
* **ALFS** — Automated Linux From Scratch (LFS tự động)
* **API** — Application Programming Interface (giao diện lập trình ứng dụng)
* **ASCII** — American Standard Code for Information Interchange (bảng mã chuẩn Mỹ để trao đổi thông tin)
* **BIOS** — Basic Input/Output System (hệ thống nhập/xuất cơ bản)
* **BLFS** — Beyond Linux From Scratch
* **BSD** — Berkeley Software Distribution
* **chroot** — change root (đổi thư mục gốc)
* **CMOS** — Complementary Metal Oxide Semiconductor
* **COS** — Class Of Service (lớp dịch vụ)
* **CPU** — Central Processing Unit (bộ xử lý trung tâm)
* **CRC** — Cyclic Redundancy Check (kiểm tra dư thừa tuần hoàn)
* **CVS** — Concurrent Versions System
* **DHCP** — Dynamic Host Configuration Protocol (giao thức cấu hình host động)
* **DNS** — Domain Name Service (dịch vụ tên miền)
* **EGA** — Enhanced Graphics Adapter
* **ELF** — Executable and Linkable Format (định dạng thực thi và liên kết)
* **EOF** — End of File (kết thúc tệp)
* **EQN** — equation (phương trình)
* **ext2** — second extended file system (hệ thống tệp mở rộng thứ hai)
* **ext3** — third extended file system (hệ thống tệp mở rộng thứ ba)
* **ext4** — fourth extended file system (hệ thống tệp mở rộng thứ tư)
* **FAQ** — Frequently Asked Questions (câu hỏi thường gặp)
* **FHS** — Filesystem Hierarchy Standard (chuẩn phân cấp hệ thống tệp)
* **FIFO** — First-In, First-Out (vào trước, ra trước)
* **FQDN** — Fully Qualified Domain Name (tên miền đầy đủ)
* **FTP** — File Transfer Protocol (giao thức truyền tệp)
* **GB** — Gigabyte
* **GCC** — GNU Compiler Collection (bộ biên dịch GNU)
* **GID** — Group Identifier (định danh nhóm)
* **GMT** — Greenwich Mean Time (giờ trung bình Greenwich)
* **HTML** — Hypertext Markup Language (ngôn ngữ đánh dấu siêu văn bản)
* **IDE** — Integrated Drive Electronics
* **IEEE** — Institute of Electrical and Electronic Engineers (Viện Kỹ sư Điện và Điện tử)
* **IO** — Input/Output (nhập/xuất)
* **IP** — Internet Protocol (giao thức Internet)
* **IPC** — Inter-Process Communication (giao tiếp liên tiến trình)
* **IRC** — Internet Relay Chat
* **ISO** — International Organization for Standardization (Tổ chức Tiêu chuẩn hóa Quốc tế)
* **ISP** — Internet Service Provider (nhà cung cấp dịch vụ Internet)
* **KB** — Kilobyte
* **LED** — Light Emitting Diode (điốt phát sáng)
* **LFS** — Linux From Scratch
* **LSB** — Linux Standard Base
* **MB** — Megabyte
* **MBR** — Master Boot Record (bản ghi khởi động chính)
* **MD5** — Message Digest 5
* **NIC** — Network Interface Card (card mạng)
* **NLS** — Native Language Support (hỗ trợ ngôn ngữ bản địa)
* **NNTP** — Network News Transport Protocol
* **NPTL** — Native POSIX Threading Library
* **OSS** — Open Sound System
* **PCH** — Pre-Compiled Headers (tiêu đề biên dịch trước)
* **PCRE** — Perl Compatible Regular Expression (biểu thức chính quy tương thích Perl)
* **PID** — Process Identifier (định danh tiến trình)
* **PTY** — pseudo terminal (terminal giả)
* **QOS** — Quality Of Service (chất lượng dịch vụ)
* **RAM** — Random Access Memory (bộ nhớ truy cập ngẫu nhiên)
* **RPC** — Remote Procedure Call (gọi thủ tục từ xa)
* **RTC** — Real Time Clock (đồng hồ thời gian thực)
* **SBU** — Standard Build Unit (đơn vị dựng chuẩn)
* **SCO** — The Santa Cruz Operation
* **SHA1** — Secure-Hash Algorithm 1 (thuật toán băm an toàn 1)
* **TLDP** — The Linux Documentation Project
* **TFTP** — Trivial File Transfer Protocol
* **TLS** — Thread-Local Storage (vùng lưu trữ cục bộ theo luồng)
* **UID** — User Identifier (định danh người dùng)
* **umask** — user file-creation mask (mặt nạ tạo tệp của người dùng)
* **USB** — Universal Serial Bus (bus nối tiếp đa năng)
* **UTC** — Coordinated Universal Time (giờ phối hợp quốc tế)
* **UUID** — Universally Unique Identifier (định danh duy nhất toàn cầu)
* **VC** — Virtual Console (console ảo)
* **VGA** — Video Graphics Array
* **VT** — Virtual Terminal (terminal ảo)
