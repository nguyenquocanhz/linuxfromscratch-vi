# 6.2. M4-1.4.20

Gói M4 chứa một bộ xử lý macro.

* **Thời gian dựng ước tính:** 0.1 SBU
* **Dung lượng đĩa cần:** 38 MB

## 6.2.1. Cài đặt M4

Chuẩn bị biên dịch M4:

```bash
./configure --prefix=/usr   \
            --host=$LFS_TGT \
            --build=$(build-aux/config.guess)
```

Biên dịch gói:

```bash
make
```

Cài đặt gói:

```bash
make DESTDIR=$LFS install
```

Chi tiết về gói này nằm trong [Mục 8.13.2, “Nội dung của M4.”](../chapter08/m4.md#contents-m4)
