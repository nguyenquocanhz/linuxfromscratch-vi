# Linux From Scratch tiếng Việt

Sách Linux From Scratch 12.4 · bản System V · tiếng Việt

**Tự tay dựng một hệ điều hành Linux, từng dòng lệnh một.**

Linux From Scratch (LFS) hướng dẫn bạn biên dịch toàn bộ hệ thống Linux từ mã nguồn — từ trình biên dịch, thư viện C cho tới kernel. Đây là bản dịch tiếng Việt cho cộng đồng, kèm [trick lỏ](trick-lo.md) để bạn đỡ vấp những cái hố mà ai cũng từng rơi vào.
