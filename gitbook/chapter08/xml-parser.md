# 8.44. XML::Parser-2.47

Mô-đun XML::Parser là giao diện Perl tới bộ phân tích XML của James Clark, Expat.

* **Thời gian dựng ước tính:** dưới 0.1 SBU
* **Dung lượng đĩa cần:** 2.4 MB

## 8.44.1. Cài đặt XML::Parser

Chuẩn bị biên dịch XML::Parser:

```bash
perl Makefile.PL
```

Biên dịch gói:

```bash
make
```

Để kiểm thử kết quả, chạy:

```bash
make test
```

Cài đặt gói:

```bash
make install
```
