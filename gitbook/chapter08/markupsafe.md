# 8.74. MarkupSafe-3.0.2

MarkupSafe là một module Python cài đặt chuỗi an toàn cho markup XML/HTML/XHTML.

* **Thời gian dựng ước tính:** dưới 0.1 SBU
* **Dung lượng đĩa cần:** 500 KB

## 8.74.1. Cài đặt MarkupSafe

Biên dịch MarkupSafe bằng lệnh sau:

```bash
pip3 wheel -w dist --no-cache-dir --no-build-isolation --no-deps $PWD
```

Gói này không đi kèm bộ kiểm thử.

Cài đặt gói:

```bash
pip3 install --no-index --find-links dist Markupsafe
```

## 8.74.2. Nội dung của MarkupSafe

* **Thư mục được cài:** /usr/lib/python3.13/site-packages/MarkupSafe-3.0.2.dist-info
