# 8.13. M4-1.4.20

Gói M4 chứa một bộ xử lý macro.

* **Thời gian dựng ước tính:** 0.4 SBU
* **Dung lượng đĩa cần:** 60 MB

## 8.13.1. Cài đặt M4

Chuẩn bị biên dịch M4:

```bash
./configure --prefix=/usr
```

Biên dịch gói:

```bash
make
```

Để kiểm thử kết quả, chạy:

```bash
make check
```

Cài đặt gói:

```bash
make install
```

## 8.13.2. Nội dung của M4

* **Chương trình được cài:** m4

### Mô tả ngắn

* `m4` — Sao chép các tệp được chỉ định đồng thời mở rộng các macro trong đó. Các macro này có thể có sẵn hoặc do người dùng định nghĩa và nhận số đối số tùy ý. Ngoài việc mở rộng macro, `m4` còn có các hàm dựng sẵn để chèn tệp theo tên, chạy lệnh Unix, tính toán số nguyên, xử lý văn bản, đệ quy, v.v. Chương trình `m4` có thể dùng làm front end cho trình biên dịch, hoặc như một bộ xử lý macro độc lập
