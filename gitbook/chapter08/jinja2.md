# 8.75. Jinja2-3.1.6

Jinja2 là một module Python cài đặt một ngôn ngữ mẫu (template) đơn giản theo phong cách Python.

* **Thời gian dựng ước tính:** dưới 0.1 SBU
* **Dung lượng đĩa cần:** 2.6 MB

## 8.75.1. Cài đặt Jinja2

Dựng gói:

```bash
pip3 wheel -w dist --no-cache-dir --no-build-isolation --no-deps $PWD
```

Cài đặt gói:

```bash
pip3 install --no-index --find-links dist Jinja2
```

## 8.75.2. Nội dung của Jinja2

* **Thư mục được cài:** /usr/lib/python3.13/site-packages/Jinja2-3.1.6.dist-info
