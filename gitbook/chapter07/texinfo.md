# 7.11. Texinfo-7.2

Gói Texinfo chứa các chương trình để đọc, viết và chuyển đổi các trang info.

* **Thời gian dựng ước tính:** 0.2 SBU
* **Dung lượng đĩa cần:** 152 MB

## 7.11.1. Cài đặt Texinfo

Chuẩn bị biên dịch Texinfo:

```bash
./configure --prefix=/usr
```

Biên dịch gói:

```bash
make
```

Cài đặt gói:

```bash
make install
```

Chi tiết về gói này nằm trong [Mục 8.72.2, “Nội dung của Texinfo.”](../chapter08/texinfo.md#contents-texinfo)
