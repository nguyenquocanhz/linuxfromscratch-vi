# 2.1. Giới thiệu

Trong chương này, các công cụ trên máy host cần thiết để dựng LFS sẽ được kiểm tra và, nếu cần, được cài đặt. Sau đó chúng ta chuẩn bị một phân vùng để chứa hệ thống LFS: tạo phân vùng, tạo hệ thống tệp trên đó rồi mount nó.
